# 🍔 FoodRush — Food Delivery Web Application

### From Craving to Delivered

## 📌 About the Project
FoodRush is a modern food delivery web application designed to make online food ordering simple, convenient, and user-friendly.

## ✨ Features
- User authentication and login
- Restaurant browsing and food menus
- Shopping cart and checkout
- Online payment integration
- Order tracking and order history
- Restaurant order management
- Responsive user interface

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **Backend Services:** Supabase / Lovable Cloud
- **Development Platform:** Lovable
- **Version Control:** GitHub

## 🏗️ Architecture
Customer → React Application → Backend Services → Database

## ⚙️ Installation
```bash
git clone https://github.com/Deepamadesh/foodrush.git
cd foodrush
npm install
npm run dev
```
